Judith Bali GitHub Pages website

Upload the contents of this folder to the ROOT of a new GitHub repository. Enable GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root). Do not change judithbali.com DNS until ready.

The five PDFs are unmodified copies of the user-provided files. The cover PNGs are rendered from page 1 of each PDF. Home and book descriptions are transcribed from the public Weebly pages. Contact form omitted because it requires Weebly infrastructure.
